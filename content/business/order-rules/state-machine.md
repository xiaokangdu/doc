# 状态机

> 用状态机描述订单状态的合法流转，避免非法状态跳转。

## 状态定义

| 状态 | 说明 |
| --- | --- |
| 待支付 | 订单已创建 |
| 已支付 | 支付成功 |
| 已发货 | 仓库已发出 |
| 已完成 | 确认收货 |
| 已取消 | 超时或主动取消 |

## 流转

~~~text
待支付 --支付--> 已支付
已支付 --发货--> 已发货
已发货 --确认收货--> 已完成
待支付 --超时/取消--> 已取消
~~~

## 注意事项

1. 每个动作都要校验当前状态是否允许
2. 状态变更与业务副作用放在同一事务
3. 保留状态变更日志便于排查
