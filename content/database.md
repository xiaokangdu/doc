# 数据库

> 统一沉淀各类数据库的使用要点、语法差异与踩坑记录，目前覆盖 OceanBase、Oracle、MySQL。

## 概览

- **OceanBase**：分布式 HTAP 数据库，兼容 MySQL 协议
- **Oracle**：企业级关系型数据库，PL/SQL 与优化器成熟
- **MySQL**：使用最广的开源关系型数据库

## 学习路径

1. 先过一遍基础语法：建表、增删改查、分页
2. 再整理常用函数与执行计划
3. 最后沉淀易错点与性能陷阱

## 快速对比

| 维度 | OceanBase | Oracle | MySQL |
| --- | --- | --- | --- |
| 部署形态 | 分布式集群 | 集中式 / RAC | 单机 / 主从 |
| SQL 方言 | MySQL 兼容 | 自有 + PL/SQL | MySQL |
| 典型场景 | 高并发海量数据 | 复杂事务与存储过程 | 互联网业务 |
