# Oracle

> 成熟的企业级关系型数据库，PL/SQL 存储过程与优化器工具链完善。

## 特点

- 企业级事务与稳定性
- PL/SQL 生态完善
- 执行计划分析工具成熟

## 核心概念

| 概念 | 说明 |
| --- | --- |
| 表空间 | 数据文件的逻辑分组 |
| 序列 | 生成唯一自增主键 |
| 同义词 | 数据库对象的别名 |

## 连接示例

~~~sql
sqlplus scott/tiger@//127.0.0.1:1521/ORCLPDB1
~~~
