# 基础语法

> 变量、类型与流程控制是写 Java 的第一课。

## 语言特点

- 强类型，编译期检查严格
- 面向对象，一切皆对象
- 基于 JVM，一次编写到处运行
- 自动内存管理（GC）

## 知识点

- [变量与类型](java/basics/types)
- [流程控制](java/basics/control)

## 第一个程序

~~~java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java");
    }
}
~~~
