## 高频命令

~~~bash
git status
git add .
git commit -m "message"
git push origin main
~~~

## 工作区模型

| 区域 | 说明 |
| --- | --- |
| 工作区 | 正在编辑的文件 |
| 暂存区 | 准备提交的快照 |
| 本地仓库 | 已提交的历史 |
| 远程仓库 | GitHub 等平台 |
