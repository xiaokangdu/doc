# 欢迎来到我的笔记库

这里沉淀我在**工程实践、前端基础与效率工具**上积累的零散知识。
站点是纯静态的，新增一篇笔记只需要两个动作：新建 Markdown 文件、在菜单里登记一行。

> 左侧是分级菜单，顶栏支持全文搜索，右上角的 🎲 可以随机翻一篇。

## 快速上手

1. 从左侧目录选择主题，逐级展开子菜单
2. 在顶栏输入关键词，可搜索标题与正文
3. 每篇笔记右侧会自动生成本页目录

## 如何持续新增网页

~~~text
第 1 步：在 content/notes/ 下新建 xxx.md，用 # 写标题
第 2 步：在 content/nav.json 对应分组里加一条：
         { "title": "标题", "path": "notes/xxx" }
第 3 步：刷新页面，左侧菜单、面包屑与搜索会自动包含新页面
~~~

## 设计原则

- **轻量**：零构建、零依赖，直接丢到 GitHub Pages 即可运行
- **可扩展**：菜单是数据驱动的，层级不限、顺序随你
- **好阅读**：浅色主题、适中留白、克制的交互动画

更完整的维护与发布方式，见 [站点使用指南](guide)。
